## Category 1 — CSRF: Raw `fetch` on Mutating Endpoints

**Root cause**: `secureFetch` from `$lib/utils/csrf.js` injects the CSRF token header. Raw `fetch()` on POST/PATCH/DELETE endpoints returns 403 "Invalid CSRF token". This burned us in S89 (3 callers), S93 upload page (4 callers), and now 7 more.

**All fixed in this session:**

| File | Method | Endpoint | Fixed |
|------|--------|----------|-------|
| `routes/dashboard/rm/policies/[lenderId]/[product]/+page.svelte:87` | POST | `/api/pms/policies/${id}/revise` | ✅ |
| `routes/dashboard/dsa/team/+page.svelte:79` | DELETE | `/api/team/members/${userId}` | ✅ |
| `routes/dashboard/dsa/team/+page.svelte:85` | PATCH | `/api/team/members/${userId}` | ✅ |
| `routes/dashboard/dsa/crm/leads/+page.svelte:85` | POST | `/api/leads/${leadId}/convert` | ✅ |
| `lib/components/dashboard/DocumentUpload.svelte:84` | POST | `/api/cases/.../upload` | ✅ |
| `lib/components/DemoBanner.svelte:8` | POST | `/api/auth/logout` | ✅ |
| `lib/components/DemoRestrictionModal.svelte:13` | POST | `/api/auth/logout` | ✅ |

**Rule**: Every `fetch()` call with method POST/PUT/PATCH/DELETE in `.svelte` or client `.ts` files must use `secureFetch`. GET is safe with raw fetch. File uploads (FormData body) work fine with secureFetch — it adds the CSRF header only, not Content-Type.

## Category 2 — SSR Crash: Browser-Only Packages at Module Scope

**Root cause**: Capacitor plugin CJS files call `window.*` / `document.*` at module-load time. Static `import` at module scope causes these to execute during SSR (both Vite dev and Vercel prod), throwing TypeError and returning 500.

### Fixed in S93 session:

#### `@capacitor/network` — `src/lib/utils/api.ts` ✅
`plugin.cjs.js:83` calls `new NetworkWeb()` → `window.addEventListener` at module load.
**Fix**: Moved `import { Network }` from module scope to `await import('@capacitor/network')` inside `fetchWithPlatformSupport()`.

#### `gsap/dist/ScrollTrigger` — `src/lib/utils/gsapSetup.ts` ✅
`ScrollTriggerPkg` resolves to `undefined` during Vite dev SSR (CJS subpath interop gap).
`(undefined as any).ScrollTrigger` threw TypeError.
**Fix**: Null-guard before dereferencing; skip `registerPlugin` when undefined.

### Latent risk (MEDIUM — not yet crashing):

#### `@capacitor/preferences` — 3 files
| File | Line | Notes |
|------|------|-------|
| `lib/storage/formPersistence.ts` | 2 | Module-scope import; runtime usage guarded by `if (browser)` |
| `lib/state/form.svelte.ts` | 13 | Module-scope import; runtime usage guarded by `if (browser)` |
| `lib/utils/formStateHelpers.ts` | 9 | Module-scope import; runtime usage guarded by `if (browser)` |

`@capacitor/preferences` uses dynamic imports internally (lower risk than `@capacitor/network`), but the module-scope `import` still loads and evaluates the package during SSR. Monitor — convert to lazy `await import('@capacitor/preferences')` inside functions if SSR errors appear.

**Rule for Capacitor plugins**: Never use static `import` at module scope for any `@capacitor/*` plugin other than `@capacitor/core`. Use `await import(...)` inside the function that needs it, or gate with `if (browser)` and use lazy import.

**Thenable trap when wrapping the import** (S94, commit `2ff2d747` — CLAUDE.md pitfall #8): if you write a lazy-import helper, **never return the Capacitor proxy directly from an async function**. Capacitor namespaces are JavaScript Proxies that intercept every property access — including `.then`. JavaScript's `await` operator detects `.then` on the resolved value and tries to unwrap it as a Promise, which calls the proxy's `.then` as if it were a plugin method. Capacitor errors with `"X.then() is not implemented on web"`, surfacing as the landing-page ErrorBoundary fallback ("Failed to load some content. Please refresh."). Wrap the result in a plain object envelope so `.then` is undefined: `return { Preferences: mod.Preferences }`. See [`src/lib/utils/capacitorPreferences.ts`](../../src/lib/utils/capacitorPreferences.ts) for the canonical pattern. Same caveat applies to any Proxy-based API awaited via async return.
